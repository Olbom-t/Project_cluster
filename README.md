# Пилот кластеризации результатов выборов

Это исследовательский запуск согласованной постановки: отдельная модель для
каждого региона и кампании; все именованные доли от действительных голосов;
равный вес УИК. Без VIF, PCA, ILR, стандартизации столбцов и весов по численности.
Сравниваются k-means, Ward, регуляризованная GMM и HDBSCAN.
Это ещё не окончательный продукт и не окончательно принятая методика выбора K.

Результаты в `results/`, подготовленные входы в `data/`.
`data/manifest.json` содержит перечень активных исходников и SHA256.
В пакет включены подготовленные данные, поэтому повторение моделей работает
офлайн после установки зависимостей из `requirements-pilot.txt`.
Исходные CSV не изменяются. Старые файлы дума2026 не используются.

Из корня проекта:

```bash
python -m pilot.centroid_hierarchy --method kmeans
python -m pilot.centroid_hierarchy --method ward
python -m pilot.gmm
python -m pilot.hdbscan
python -m pilot.refinement
python -m pilot.selection_stability
python -m unittest pilot.test_validation
python -m pilot.build_report
```

Полный повтор — исследовательский расчёт, а не мгновенное присвоение меток.
Первичная подготовка `python -m pilot.prepare` требует исходных вложений в
`/workspace/attachments`; для повторения моделей она не нужна, поскольку
готовые входные матрицы сохранены. Нужен Python 3.12 или совместимый с указанными
версиями пакетов. Сетевых запросов при расчётах нет.

В `assignments.csv` есть исходные идентификаторы, дополнительные протокольные
показатели, метка и внутренняя устойчивость назначения. В `profiles.csv` —
машинные значения средних долей и диапазонов. Карты, диаграммы и таблицы
территориального распределения не строились.

Основные ограничения: силуэт оценивается на одинаковой фиксированной выборке
до 1500 УИК; устойчивость при фиксированных параметрах — 30 подвыборок 80%;
это внутренняя описательная проверка на общих обучающих наблюдениях. Для выбора
K есть отдельная предварительная проверка из 10 повторений. Никакая частота
назначения не является вероятностью истинного электорального типа.

У GMM ковариация регуляризована параметром модели; исходные доли не изменены.
У HDBSCAN силуэт и ARI по назначенной части нужно читать вместе с охватом,
переходами в шум и устойчивостью отдельных групп. Метки C01 и т.д. локальны
для конкретного варианта модели, не сопоставляются между кампаниями.
